# Calculator Project

A simple calculator project containing implementations in **Python**, **HTML**, and **JavaScript**.

## Files

| File              | Description                                                        |
| ----------------- | ------------------------------------------------------------------ |
| `calculator.py`   | Command-line calculator in Python (add, subtract, multiply, divide) |
| `index.html`      | Interactive web calculator with keyboard support                  |
| `calculator.js`   | Pure JavaScript calculator logic module                            |

## Python Calculator

Run it from the terminal:

```bash
python calculator.py
```

Then follow the on-screen prompts to choose an operation and enter two numbers.

## Web Calculator (HTML + JavaScript)

Just open `index.html` in any web browser — no server needed.

Features:
- Click the on-screen buttons, or use your keyboard
- Supports `+`, `-`, `*`, `/`, parentheses, and decimals
- `Enter` = calculate, `Backspace` = delete last, `Escape` = clear all
